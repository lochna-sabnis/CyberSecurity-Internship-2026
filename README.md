## 🔍 Capstone Highlights

The Week 4 assessment examined common web application security weaknesses in OWASP Juice Shop.

| Security finding | Severity |
|---|---|
| SQL injection authentication bypass | Critical |
| Cross-site scripting (XSS) | High |
| Insecure session/token handling | High |
| Exposed directory and sensitive-looking files | High |
| Missing Content-Security-Policy header | Medium |
| Wildcard CORS policy | Medium |
| Information disclosure through `robots.txt` | Low |
| Unexpected open port | Low |

*These findings are documented in the capstone report. Testing was conducted against the intentionally vulnerable local lab application.*
