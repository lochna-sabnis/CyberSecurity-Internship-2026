# CyberSecurity-Internship-2026 - Skill Set Go EduTech
4-week practical Cybersecurity internship track covering networking fundamentals, Linux system security, ethical hacking (OWASP-based), threat detection, and a final security assessment capstone.

## 🎯 Objective
Build foundational and applied cybersecurity skills through hands-on tasks — from network/Linux basics to a complete security assessment with professional reporting.

## 🛠️ Tools & Environment
- VirtualBox + Kali Linux (practice environment)
- Docker + OWASP Juice Shop (legal vulnerability practice target)
- Linux terminal (permissions, users, hardening exercises)

## 📁 Repository Structure
├── Week1/ → Security Foundations (networking, Linux security, threat ID, basic assessment)
├── Week2/ → Ethical Hacking & Web Security (OWASP Top 10, vulnerability findings, pen-test report)
├── Week3/ → SOC & Threat Detection (log analysis, monitoring dashboard)
├── Week4/ → Cybersecurity Capstone (risk register, IR procedure, final report)
